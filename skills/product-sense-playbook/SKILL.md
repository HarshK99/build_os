# Product Sense Playbook

The playbook is one file. Read it before doing anything else in this task:

`D:\FounderMode\build_os\PRODUCT_SENSE_PLAYBOOK.md`

It builds on my shared instructions, How I Work, which you already have.

Then:

1. **Find where it stands.** From `docs/product_sense.md` and the spec's feature table, work out whether this is a new pass, a pass to finish, a new feature (section 3), or a feature-table check (section 4). Tell me which in one line.
2. **Ask one step at a time,** each as a pick-from-options question, and wait for my answer before the next.
3. **Write the file only after every step is answered.**
4. **Report what didn't fit,** so the playbook gets corrected.

If the file cannot be read, say so and stop. Don't work from memory of it.
