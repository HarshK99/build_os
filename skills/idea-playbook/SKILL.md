# Idea Playbook

The playbook is one file. Read it before doing anything else in this task:

`D:\FounderMode\Apps\build_os\IDEA_PLAYBOOK.md`

It builds on my shared instructions, How I Work, which you already have.

Then:

1. **Find the step.** Look in `D:\FounderMode\planning\` for the folder of the hunt I mean, and work out which of the five steps it has reached from `research.md` and `directions.md`. With no folder yet, it is step A. Tell me the step in one line.
2. **Do one step,** using that step's section, and stop at its gate.
3. **Keep to rule 1.** Ask nothing about me as a person. The only questions about me are what I know and who I can reach, and only in step A.
4. **Step B uses the `customer-research` skill.** Quotes stay exactly as written, each with its link.
5. **Report what didn't fit.** If a step felt long or the playbook was wrong for this hunt, tell me, so it gets corrected.

If the file cannot be read, say so and stop. Don't work from memory of it.
