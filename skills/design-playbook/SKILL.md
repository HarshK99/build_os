# Design Playbook

The playbook is one file. Read it before doing anything else in this task:

`D:\FounderMode\build_os\DESIGN_PLAYBOOK.md`

It builds on my shared instructions, How I Work, which you already have. This skill is not a design skill: the playbook's section 2 says which one design skill leads.

Then:

1. **Find the situation.** From the project's files (`docs/product_sense.md`, the feature table, `docs/design.md`, `docs/design/mockups/`), work out which row of the playbook's section 1 applies and which step is next. Tell me both in one line.
2. **Do one step at a time,** asking with options, and wait for my answer before the next.
3. **Report what didn't fit,** so the playbook gets corrected.

If the file cannot be read, say so and stop. Don't work from memory of it.
