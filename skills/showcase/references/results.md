# Results mode

The user is reporting how a posted video or a post on X did.

## Steps

1. Find the script it belongs to. If it was never logged, ask the user for it and run shot mode first, since results need a script to attach to.
2. Add one row to the script's Results table with today's date and the numbers given. The columns depend on the script's `platform` and are listed in `shot.md`. Leave unknown columns empty. Numbers change over time, so each report is a new row and earlier rows stay.
3. If the script's idea used a swipe pattern, update the one-line result under "Used in" on that swipe entry.
4. Tell the user what the numbers suggest, only as far as they support it:
   - with one video or post for this app on this platform, say what happened and avoid conclusions
   - with several, compare hooks, angles, and patterns, and say which seem to work for this ICP
   - compare within a platform only; views on a reel and impressions on a post do not measure the same thing
   - for instalments of one X series, compare them with each other, since the format is constant and only the week's facts change
5. If it did well, remind the user in one line that the app has unused ideas and that `/showcase` or `/showcase x` will pick up from them.
