# App Playbook

The playbook is one file. Read it before doing anything else in this task:

`D:\FounderMode\build_os\APP_PLAYBOOK.md`

It builds on my shared instructions, How I Work, which you already have. Its product-sense and design stages are in their own playbooks; read those when the work reaches them.

Then:

1. **Find the stage.** Work out which of the six stages this app is in from its files: `docs/product_sense.md`, `docs/PRD.md`, `docs/design.md`, the architecture doc and the plan, `docs/STATUS.md`. Tell me the stage in one line.
2. **Check the gate before it.** If the previous stage's gate has not passed, say what is missing and stop there.
3. **Do only the stage I asked for.**
4. **Report what didn't fit,** so the playbook gets corrected.

If the file cannot be read, say so and stop. Don't work from memory of it.
