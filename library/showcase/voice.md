# Voice guide

How the user talks on camera and writes in posts. It is built up from interview answers, the scripts they actually shot, and the posts they published; every point carries a quoted example, the id of the record it came from, and a tag: `spoken` or `written`.

Use `spoken` points for reel scripts and `written` points for posts. Where only the other kind exists, treat it as a weak hint.

While a section is empty, write plainly and short, the way someone would say it aloud, and do not invent a persona.
